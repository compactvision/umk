# Progression conditionnelle

Le jury doit publier un mode `conditional` défini par son règlement. Le passage exige un niveau suivant, une liste d’UE non acquises et une échéance dans l’année cible. L’échéance est visible dans le dossier. Une échéance dépassée bloque le démarrage d’une réinscription et le nouveau rattachement d’une offre de reprise.

Une inscription déjà créée conserve son état Enrollment. Toute décision consécutive à l’échec d’une condition doit être instruite par les autorités. La progression n’attribue ni note ni crédit.
