# Intégration aux cours et séances

La fiche de cours reste l’entrée côté étudiant. Fichiers réunit les supports, syllabus et audios. Les liens et vidéos gardent leurs rubriques. La recherche se fait sur le titre dans le cours courant et dans les offres permises par l’inscription annuelle, le groupe et les inscriptions pédagogiques existantes.

Une ressource peut pointer vers une séance de la même offre. Le détail d’une séance visible propose un lien vers ses ressources si le dossier a accès à au moins un support associé. Les ressources restent dans le cours lorsque la séance est annulée. Une séance invisible ne fournit pas ses métadonnées à travers un support visible.

Pour une offre versionnée, la sélection des cours et les titres de référence suivent le service académique de la fiche étudiante. Le filtre Programme de la bibliothèque administrative suit le programme de la maquette. Les offres historiques sont consultables via les autres filtres.
