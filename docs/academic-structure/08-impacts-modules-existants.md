# Effets sur les modules existants

| Module | Intégration et continuité |
|---|---|
| Admissions | Le niveau et les pièces existantes restent la base ; le choix du programme est conservé dans le dossier si applicable |
| Inscriptions | Une référence optionnelle à la maquette et à la cohorte, sans reprise automatique de l'historique |
| Portail étudiant | Pour un dossier rattaché, libellés et caractéristiques de référence viennent de la version ; sinon, lecture historique du catalogue |
| Cours et enseignement | La matière pointe sur le cours existant ; l'offre annuelle, son enseignant et ses droits restent le point d'accès opérationnel |
| Horaires et ressources | Séances et fichiers restent liés aux offres existantes ; la maquette filtre le périmètre sans déplacer ni republier ces données |
| Finances | Tarifs, obligations et paiements gardent leurs références et montants |
| Résultats | Les IDs de référence sont disponibles pour une phase ultérieure ; aucun recalcul |
| Documents | L'identité officielle est disponible via l'université et le Site ; aucun changement de génération ni réédition historique |

Dans l'administration, **Structure académique** regroupe l'institution, les programmes, les référentiels et les maquettes. Le détail donne les révisions, comparaisons, décisions, étudiants concernés et dossiers historiques à examiner. La comparaison porte sur les matières et leurs unités ; une matière déplacée est affichée comme retrait puis ajout.
