# Suite des travaux

1. Sur une copie autorisée, contrôler les temps de migration et valider les droits, sauvegardes et processus de restauration. Tester un premier programme de référence avec le service académique.
2. Rattacher les anciennes inscriptions uniquement sur preuves. Constituer une liste des cas qui nécessitent une décision d'équivalence, de reprise ou de dérogation.
3. Introduire les notes et décisions avec des références immuables d'inscription et de matière. Définir ensuite les transitions auditées de cursus ; garder les résultats antérieurs reproductibles.
4. Relier les périodes de maquette aux calendriers réels lorsque les parcours sortent du calendrier semestriel. Structurer les campus/salles lorsque l'inventaire et les usages le justifient.
5. Avant un deuxième établissement, réaliser l'isolation complète décrite dans la [stratégie multi-universités](06-strategie-multi-universites.md).
6. Mesurer ensuite les parcours avec des volumes représentatifs : requêtes SQL, p95/p99, verrous, connexions, files, cache, stockage. Les tests locaux ne certifient pas une capacité de 5 000 utilisateurs.

L'activation reste une décision de mise en service. Configurer le référentiel, vérifier une publication puis vérifier les dossiers, horaires et frais d'un groupe pilote avant de l'étendre.
