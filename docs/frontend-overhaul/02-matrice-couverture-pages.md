# Matrice de couverture Laravel et frontend

Inventaire des routes enregistrées en environnement de test. Les références UI et tests proviennent de correspondances littérales sur le nom de route ou sur un chemin statique. Les chemins construits dynamiquement, les délégations et les routes utilisées via des URL fournies par Laravel nécessitent une vérification manuelle. Les contrôles relevés dans les méthodes complètent les middlewares et doivent être confirmés avec les policies et services appelés. Une référence de test ne prouve pas la couverture du parcours. Le résultat global de la baseline est consigné dans le document 09.
